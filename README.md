# StudentAssistant 📱

**StudentAssistant** is an Android application developed as a course project at Jahangirnagar University. The app is designed to help students efficiently manage their daily tasks and personal finances through an all-in-one, user-friendly platform.

---

## 🚀 Features

### ✅ To-Do List Management
- Create, edit, and delete tasks
- Set due dates and prioritize tasks
- Receive deadline reminders
- Organize tasks by categories (e.g., academic, personal, finance)

### ✅ Personal Finance Management
- Create and monitor budgets
- Track daily expenses and categorize them
- Record and analyze income sources
- Set savings goals and track progress
- Get reminders for upcoming bills
- Visualize spending patterns with graphs and summaries
- Support for multi-currency tracking (ideal for international students)

---

## 🎯 Objectives
- Provide students with an integrated platform for managing academic tasks and finances
- Enhance productivity and reduce academic stress
- Offer budgeting and expense-tracking tools tailored for student life

---

## 💡 Motivation
Many students juggle multiple apps to manage studies and money. StudentAssistant brings **task management** and **financial tracking** into a **single, seamless experience**, simplifying student life.

---

## 🛠️ Tech Stack
- **Language:** Java  
- **Platform:** Android  
- **Architecture:** OOP, SOLID principles  
- **Design Patterns:** Singleton, Multithreading  
- **Database:** SQLite or Room
